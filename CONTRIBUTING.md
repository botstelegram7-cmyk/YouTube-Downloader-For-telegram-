# Contributing

Thanks for helping improve this project.

1. Open an issue describing the bug or feature before major changes.
2. Fork the repository and create a focused branch.
3. Use Python 3.12+ and `python-telegram-bot` 22.8.
4. Keep secrets out of source control; never commit `.env` or bot tokens.
5. Test configuration validation, URL validation, and error paths before opening a pull request.
6. Include clear reproduction steps and update the README for user-facing changes.
7. Keep changes respectful of YouTube terms, copyright, and applicable law.

Pull requests should explain the change, how it was tested, and any deployment implications.
