# Contributing

Thanks for helping improve this project.

1. Open an issue describing the bug or feature before major changes.
2. Fork the repository and create a focused branch.\n3. For the Telegram Serverless + TypeTube worker architecture, follow [deployment.md](deployment.md).
4. Use Python 3.12+ and `python-telegram-bot` 22.8.
5. Keep secrets out of source control; never commit `.env` or bot tokens.
6. Test configuration validation, URL validation, and error paths before opening a pull request.
7. Include clear reproduction steps and update the README for user-facing changes.
8. Keep changes respectful of YouTube terms, copyright, and applicable law.

Pull requests should explain the change, how it was tested, and any deployment implications.
